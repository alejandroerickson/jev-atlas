What the atlas learned

Learning round 1

E9 failed. The learner (gpt-5.5-2026-04-23) read the run and the manual:

The run went wrong on the Resources landing page reached from the project Resource tab. The page offered All estimates, the register that leads to New estimate; the atlas framed it as browsing existing estimates. Projects looked like the route back to the chosen project, so the run looped between the project and Resources.

note on “All estimates 8”
What it does, before: Opens the list of every resource estimate, any status; the number is how many there are.
What it does, after: Opens the estimate register, where New estimate starts an estimate for a project.
Not for, before: Only the estimates in review (In review). It does not create an estimate (New estimate, on the list).
Not for, after: In review is for estimates already in review; Portfolio resources is for released-value charts.
At the Resources landing page, the estimate-register route was implicit, so Projects looked more relevant.
page description: resources-portfolio
What it does, before: Landing page of Resources: in-situ value at the corporate price deck for every project with a released estimate, as headline figures (total value, estimates in review, measured + indicated share, release requests pending), charts by project, commodity and category, and a table of released estimates by project.
What it does, after: Resources landing page for released-estimate value charts and the price-deck summary.
Elsewhere, before: This page counts released estimates; drafts and estimates in review: Resource estimates (All estimates / In review). Screening with a price factor or recovery: In-situ value. The project links in the table open the project's own resource tab in Projects, and the estimate id links open the estimate.
Elsewhere, after: New estimate lives in All estimates. In review holds estimates already in review; Price deck holds commodity prices and cut-offs.
The page text routed review items, but left the starting point for a new estimate unclear.
note on “Projects”
What it does, before: Opens the Projects section: the register of exploration projects and each project's record (tenure, programmes, team, budget, gates).
What it does, after: Opens the Projects register and project records, with tabs for each project's details.
Not for, before: The portfolio-wide overview (Portfolio) or field work on a project (Programmes).
Not for, after: New estimate lives in Resources, All estimates; Resource tab shows a project's estimate history.
Projects drew the agent away from the estimate workflow on the Resources landing page.
